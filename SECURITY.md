# Security Policy

## Supported Versions

This project is currently maintained from the `main` branch.

## Reporting A Vulnerability

If you find a vulnerability or safety issue, please open a private security advisory on GitHub if available.

If private advisories are not enabled, open an issue with minimal public detail and mark it as a security or safety concern.

Examples of security or safety issues:

- instructions that encourage copyright infringement
- unsafe source verification guidance
- misleading image or attribution practices
- prompts that reliably produce deceptive or harmful content
- metadata that causes the skill to trigger in inappropriate contexts

## Response Expectations

Maintainers should acknowledge valid reports when possible and prioritize fixes that reduce legal, safety, or trust risks.

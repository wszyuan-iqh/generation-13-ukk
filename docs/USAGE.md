# Usage Guide

This guide shows how to use the `x-algorithm-content-strategist` skill after installing it in Codex.

## Basic Prompt

```text
Use x-algorithm-content-strategist for this topic:
[topic]

Target audience:
[audience]

Platform:
[platform]

Goal:
[reach / followers / conversion / authority / discussion / bookmarks]
```

## Full Content Package Prompt

```text
Use x-algorithm-content-strategist to create a full content package.

Topic:
[topic]

Account positioning:
[positioning]

Target audience:
[audience]

Target platforms:
[X/Twitter, newsletter, blog, YouTube, TikTok, Instagram, WeChat, Xiaohongshu]

Goal:
[goal]

Available sources or materials:
[links, facts, notes, photos, product details]

Requirements:
- build a broad source radar
- generate 20 topic candidates
- recommend the best topic
- generate title variants
- propose real-photo cover directions
- write the draft
- score it with the 100-point recommendation-fit rubric
- adapt it for each platform
```

## Rewrite Prompt

```text
Use x-algorithm-content-strategist to rewrite this draft.

Optimize for:
- stronger hook
- clearer thesis
- better evidence
- higher bookmark value
- more specific reply trigger
- safer source and image claims

Draft:
[paste draft]
```

## Current Events

For current events, ask the agent to verify facts before writing.

```text
Use x-algorithm-content-strategist for this current event.
Verify facts with official and reputable media sources before drafting.
Treat social posts as sentiment, not verified facts.
```

## Image Direction

For topics involving real people, places, products, sports, news, or travel, ask for real-photo-first image guidance.

```text
Include 5 cover image directions.
Prioritize real, licensed photos.
For each direction, include composition, main text, source recommendation, and licensing risk.
```

## Expected Output

A complete output usually includes:

1. Source radar summary
2. Topic matrix
3. Best topic recommendation
4. Title set
5. Cover image directions
6. Draft article/thread/script
7. Recommendation-fit score
8. Revision notes
9. Platform adaptations

# Roadmap

This roadmap is intentionally lightweight. The project should evolve through real use, issues, and pull requests.

## Near Term

- Add tested prompts for more platforms.
- Add examples in Chinese and English.
- Improve image licensing guidance.
- Add a current-event source verification checklist.
- Add example outputs for sports, AI tools, travel, and product marketing.

## Mid Term

- Add optional evaluation prompts for independent review.
- Add platform-specific scoring adjustments.
- Add reusable campaign calendar templates.
- Add multilingual localization notes.

## Long Term

- Build a small benchmark set of prompts and outputs.
- Compare scoring against real publishing outcomes.
- Add structured changelog entries based on field feedback.
- Create community-maintained examples for different niches.
